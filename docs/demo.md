# Signal Box Alpha Demo Script

## Setup

1. Open Settings.
2. Configure OpenAI, OpenRouter, or Ollama chat settings.
3. Add an embedding model before the Search / Ask step.
4. Use **Test provider** before the demo.
5. Optionally export a local backup from Settings.

## Demo Flow

1. Press `CommandOrControl+Shift+Space`.
2. Paste a messy side-project brain dump with a decision, a task, and an open question.
3. Save and process the capture.
4. Review extracted tasks, decisions, questions, sources, and the suggested project.
5. Accept or choose the project assignment.
6. Open Project Memory and review the Overview, Captures, Decisions, Tasks, Sources, Artefacts, and Questions tabs.
7. Open Artefacts, select project memory plus a few structured objects, and generate an implementation plan.
8. Save the implementation plan, then generate and copy a coding-agent prompt.
9. Open Search / Ask, index the project, and ask: "What did I decide about sync?"
10. Click **Where did I get to?** to show project recall.

## Keyboard Notes

- `CommandOrControl+Shift+Space`: quick capture.
- `CommandOrControl+1` through `CommandOrControl+6`: primary navigation.
- `CommandOrControl+K`: Search / Ask.
- `Escape`: hide the quick-capture popover.
- `CommandOrControl+Enter`: save from quick capture.
